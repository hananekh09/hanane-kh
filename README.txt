Hanane.kh — متجر الزهور

الملفات:
- index.html: محتوى الموقع
- style.css: التصميم والألوان والتوافق مع الهاتف
- script.js: السلة والتصفية وطلبات WhatsApp
- images/: صور الباقات والواجهة

طريقة التحديث على GitHub:
1) افتحي مستودع hanane-kh على GitHub.
2) ارفعي/استبدلي index.html وstyle.css وscript.js في جذر المستودع.
3) ارفعي مجلد images كاملًا بما فيه الصور الأربع والخامسة.
4) اضغطي Commit changes وانتظري اكتمال Actions.
5) حدّثي الموقع مع Ctrl+F5.

مهم: رقم WhatsApp الحالي تجريبي (213000000000). قبل استقبال الطلبات، افتحي script.js واستبدلي القيمة برقمك الدولي من دون + أو مسافات.
الأسعار المعروضة أمثلة ويمكن تعديلها في index.html.
