موقع Hanane.kh لبيع الورود — ملفات الموقع

الملفات:
- index.html: بنية الموقع ومحتواه.
- style.css: التصميم والألوان والتجاوب مع الهاتف.
- script.js: تصفية الباقات، المفضلة، سلة الطلبات وطلب واتساب.

للتجربة:
1. فك ضغط الملف.
2. افتح index.html في المتصفح.
3. لتفعيل الطلب عبر واتساب، افتح script.js وابحث عن 213000000000 واستبدله برقم واتساب متجرك بصيغة دولية دون + أو مسافات. مثال الجزائر: 213XXXXXXXXX.
4. الأسعار والصور والنصوص تجريبية ويمكن تعديلها قبل النشر.
5. الصور والخط يجري تحميلها من الإنترنت، لذلك تحتاج اتصالًا بالإنترنت لعرضها.

للنشر عبر GitHub Pages:
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات الثلاثة مباشرة إلى جذر المستودع: index.html وstyle.css وscript.js.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واضغط Save.
5. انتظر ظهور رابط الموقع في صفحة Pages.
